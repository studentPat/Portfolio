## Deliberate omissions

- **Profile/avatar sprite:** Needs an owner-supplied or explicitly approved source image; no generated likeness is proposed.
- **Project screenshots:** Deferred until the owner selects material and grants reuse approval.
- **Pixel cursor:** Rejected; ordinary cursor behavior is more usable and accessible.
- **Sound effects:** Rejected by default. If later requested, they must be opt-in, never autoplay, and have a verified license.
- **Paid packs:** Not required. The design system must remain complete without them.

## Asset intake checklist for a later phase

- [ ] Confirm asset is still available from its original source.
- [ ] Read included license and reconcile it with source-page terms.
- [ ] Record source URL, creator, license, file name, and use location.
- [ ] Check visual pixel density against the 4px grid rules.
- [ ] Optimize file size and write appropriate alt-text decision.
- [ ] Obtain owner approval before adding the file to the repository.
