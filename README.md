# Personal Portfolio Website

## Overview

This repository will contain a professional, responsive personal portfolio website. It is intended to showcase verified background information, technical competencies, academic projects, education, certifications, and professional connections.

## Current status

The project is in Phase 1 — Project Initialization. No website pages, UI components, visual theme, personal content, or application features have been implemented.

## Technology stack

- PHP
- HTML5
- CSS3
- Vanilla JavaScript

The project avoids unnecessary frameworks and dependencies. Future additions require an approved need.

## Development workflow

Each feature follows an approval-based vertical-slice process:

1. Requirements analysis
2. Plan, file-impact, and acceptance-criteria proposal
3. User approval
4. Implementation
5. Testing and issue fixes
6. Documentation update

See [AGENTS.md](AGENTS.md) for durable agent instructions and [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md) for the phase roadmap.

## Setup

Application setup instructions will be added when the approved implementation establishes the project structure and target PHP environment. Until then, no application runtime is required.

## Contributing

Keep changes focused, readable, tested, and documented. Do not begin a feature without an approved plan. See [CHANGELOG.md](CHANGELOG.md) for project history.
