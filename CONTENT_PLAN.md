### LibraSys

**Short description**

> A course-aligned library-management prototype that combines an ASP.NET Core API, a vanilla JavaScript browser client, and a MySQL database for catalog, borrowing, reservation, fine, payment, and staff workflows.

**Detailed description**

> LibraSys models the day-to-day workflows of a single library branch beyond a basic book catalog. It includes searchable catalog access, member accounts, borrowing and returns, reservation queues, fines, payments, librarian operations, reports, and audit records. The project uses ASP.NET Core 8 Web API and MySQL, with database constraints, transactions, role policies, row-locking demonstrations, and documented local test procedures. It is an ongoing course project and working local prototype, not a production-ready enterprise library platform.

### EventFlow

**Short description**

> A backend API prototype for free, in-person event registration that models event lifecycle, capacity, approval, and attendee/organizer workflows.

**Detailed description**

> EventFlow is a backend-only ASP.NET Core Web API designed to manage free, in-person events and attendee registrations. It supports public event discovery, event management, capacity checks, venue scheduling rules, approval-required registrations, cancellation, and status transitions. Its documented API uses Entity Framework Core with SQL Server and Swagger for exploration and verification. It is an experimental academic/demo prototype with development-only identities and no frontend application.
